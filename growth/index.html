04 / AI WORKFLOW & AUTOMATION

把实际工作问题转化为可复用的 Workflow

在内容研究、数据整理和日常执行中，将重复性工作逐步转化为内部工具、AI skills、workflow 与 SOP，提高研究、复盘和执行效率。

DISCOVER

爆款内容发现

汇总目标账号与内容数据，减少重复人工搜索，并支持持续内容研究。

ANALYZE

多账号内容数据整理

将分散的内容表现整理到统一视图，提高日常复盘与比较效率。

SYSTEMIZE

Codex Skills / Workflow

将重复的内容分析、生成与输出步骤整理为可复用的 AI skill / workflow。

DOCUMENT

SOP & Documentation

将有效方法整理成清晰的执行步骤，方便重复使用与团队协作。

05 / HOW I WORK

从问题，到测试，再到可复用的方法

  1. Find Signal发现有效信号
  2. Form Hypothesis明确需要验证的问题
  3. Create / Test创意开发与测试
  4. Measure观察真实数据
  5. Refine根据结果调整
  6. Systemize沉淀为工具、Workflow 或 SOP

我的工作通常从一个具体问题或用户信号开始，通过创意、测试和真实数据持续调整；当一种方法被验证有效，再将其中可重复的部分整理为下一次可以直接使用的 workflow、tool 或 SOP。
